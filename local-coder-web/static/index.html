欢迎使用 Local Coder！

  1. 点击左侧「📁」按钮浏览并选择代码文件夹
  2. 等待索引完成
  3. 在底部输入框提问，按 Enter 发送
  4. 在输入框左侧切换模式：Ask（问答）/ Plan（规划）/ Craft（编辑）
  5. 点击左侧文件树中的文件可预览/编辑代码
  6. 点击顶部「💻」按钮打开终端

提示：Enter 发送 · Shift+Enter 换行
